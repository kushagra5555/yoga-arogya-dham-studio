Azure deployment folder for Yog Arogyadham

Use this folder for static deployment:

Folder path:
D:\yoga23\yoga23\azure_deploy

Important:
- index.html is the main file Azure should open.
- Keep css, js, images, and video in the same structure.
- Do not rename folders after refresh.

Simple workflow:
1. Make website changes in the main project folder.
2. Run BUILD_SITE.bat
3. Run REFRESH_AZURE_DEPLOY.bat
4. Upload the contents of azure_deploy to Azure
